# Writeup Format

Each challenge will generally contain:

### Objective

What the challenge asks me to accomplish.

### Investigation

What I observed, what I tried, and how I approached the problem.

### Commands

Commands and tools used during the challenge.

### Solution

How the challenge was ultimately solved.

### Key Concepts

The security concepts, Linux concepts, vulnerabilities, or techniques involved.

### Lessons Learned

What I learned from solving the challenge and anything I would approach differently next time.

# My Approach

I'm using the wargames to develop **problem-solving ability**, rather than simply collecting commands or copying solutions.

My general workflow:
* Read the objective
* Enumerate
* Understand the environment
* Identify interesting behavior
* Form a hypothesis
* Test
* Exploit / solve
* Document
* Move to the next challenge
